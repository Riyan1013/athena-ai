#  Athena AI

Athena AI is a modular AI assistant built with **TypeScript** and **Discord.js**.

The project is designed with scalability in mind, separating the application core, AI providers, and platform interfaces into independent modules. Discord is the first interface for Athena, with support for additional platforms planned in the future.

>  This project is currently under active development.

## Current Features

- Discord Bot
- Slash Commands
- `/ping`
- `/help`
- `/about`
- Modular Command Architecture
- TypeScript
- Discord.js v14

## Tech Stack

- TypeScript
- Node.js
- Discord.js
- pnpm
- Zod

## Project Status

Athena AI is currently in early development. New features and improvements are added regularly as the project evolves.
